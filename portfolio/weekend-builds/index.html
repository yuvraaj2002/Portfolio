DiffStory.

View repository ↗ (opens in a new tab)

The work happened.
Now tell the story without making things up.

A coding-agent skill for turning session context and Git changes into X and LinkedIn drafts. The conversation explains the reasoning; the diff checks the claims.

Claude Code SkillPythonGitSecret Scanning

From changes to a draft.

  1. Find the evidence.Use the session, Git changes, or both.
  2. Choose the lesson.Review ranked ideas and their confidence.
  3. Check the claims.Confirm anything the diff cannot establish.
  4. Keep the final say.Review local drafts. Publish them yourself.

THE DESIGN CHOICE

Evidence before polish.

Ideas distinguish verified claims from diff-only, conversation-only, and general-knowledge claims. A compelling story is not automatically a supported one.

THE BOUNDARY

Drafts, not autopilot.

Read-only Git access, sensitive-file exclusions, and secret scanning reduce exposure. Internal names still need human review; scanning is not a confidentiality guarantee.

TRY IT IN YOUR CODING AGENT

A terminal tool.
Not another web app.

Requires Python 3.10+ and Git. Install in your Claude Code skills folder, reload skills, then run /diffstory in your coding session.
